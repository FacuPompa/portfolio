# Portfolio — Facundo Pompa

Desarrollado con React, TypeScript y Vite. Portfolio personal con enfoque en accesibilidad, performance y diseño editorial oscuro.

**Demo en vivo:** https://pompa-dev.netlify.app/

## Ejecutar localmente

```powershell
pnpm install
pnpm dev
```

## Validar producción

```powershell
pnpm lint && pnpm build && pnpm preview
```
